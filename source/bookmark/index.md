- [SYMBL](https://symbl.cc/cn) - 查 Unicode 符号和特殊字符，复制到文档里直接用
- [Emoji Cheat Sheet](https://www.webfx.com/tools/emoji-cheat-sheet) - Markdown 表情代码速查表，写作时快速找表情🍁

## JavaScript

- [fullPage.js](https://alvarotrigo.com/fullPage/zh) - 全屏滚动/单页网站插件，几行代码实现整屏切换效果
- [lunr.js](http://lunrjs.com) - 纯 JS 客户端全文搜索库，给静态站加站内搜索
- [Moment.js](http://momentjs.com) - JS 日期处理库，解析、格式化、计算时间差
- [Underscore.js](http://underscorejs.org) - JS 函数式编程工具库，提供一堆不污染原型的实用函数
